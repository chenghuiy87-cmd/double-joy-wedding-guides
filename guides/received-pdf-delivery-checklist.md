# Before sending a bilingual invitation PDF through a messaging app

An approved PDF and the copy that reaches a guest are not automatically the same viewing experience. Before sending the invitation widely, check the actual received file using your own account or device. No guest list or private invitation needs to be posted publicly.

## Keep three objects separate

1. **Editable draft:** the working file you use to make changes. Keep this private and follow the template license. It is not the invitation to distribute.
2. **Approved PDF:** the static file with the final wording, correct page count and agreed filename. This is your reference copy.
3. **Received copy:** the file or image opened from the intended delivery channel. Inspect this after sending a sample to yourself; do not judge only from a thumbnail in the chat.

## A five-step delivery check

- **Open the received item.** Confirm that it is the intended PDF or deliberately chosen image. An image preview of a document is not proof that all PDF pages were received.
- **Count the pages.** If one language is on the reverse or a later page, make sure it is present and accessible. A single screenshot can omit that entire language.
- **Read the smallest important lines.** Check both names, the event label, date, start time, venue, full address and reply instructions. Zoom in on the received copy, then compare it with the approved PDF. Re-export or change the delivery method if the text is unclear.
- **Check the response route separately.** A printed email address or website address may need to be copied or opened manually. Do not assume a PDF contains working clickable links unless you tested those links in the exported and received copies.
- **Match the event to the recipient group.** Send the tea ceremony card only to the people invited to that event. Check the relevant attachment set before each group is contacted.

## If the copy is wrong

Return to the approved PDF first. If that file is correct, change the way you attach or distribute it and repeat the received-copy check. If the PDF itself is wrong, revise the draft, export a new PDF and clearly replace the old version. Keep a private record of which version you distributed; a changed file on your computer does not update files already sent.
